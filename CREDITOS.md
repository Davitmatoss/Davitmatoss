# Créditos

- [Devicon](https://devicon.dev/) / [código-fonte](https://github.com/devicons/devicon): ícones oficiais das tecnologias. Licença em `assets/icons/LICENSE.txt`. Os nomes e logotipos pertencem aos respectivos titulares.
- [Shields.io](https://shields.io/): badges de email, GitHub e localização, seguindo o estilo das [referências de badges](https://github.com/alexandresanlim/Badges4-README.md-Profile) enviadas pelo usuário.
- [Platane/snk](https://github.com/Platane/snk): algoritmo de percurso e geração do SVG animado de contribuições. A atualização usa `Platane/snk@v3`.
- [GitHub Readme Stats](https://github.com/anuraghazra/github-readme-stats): referência de apresentação. Os números deste pacote são produzidos usando a API oficial do GitHub, sem a instância pública de cartões que falhou.
- [GitHub Profile README](https://docs.github.com/en/account-and-profile/how-tos/profile-customization/managing-your-profile-readme): estrutura do repositório de perfil.
